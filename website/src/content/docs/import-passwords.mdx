Bramble reads the export files of most password managers. On an iPhone, some apps can also send everything straight to Bramble, with no file at all.

## Import a file

1. In the app you're leaving, export your vault. [Supported apps](#supported-apps) shows which export to choose.
2. In Bramble, open **Settings → Backups** and choose **Import** next to **Import from another manager**.
3. Pick the app you're leaving, then choose the export file.
4. Bramble shows what it found. Choose **Import** to add it to the vault you have open.
5. Delete the export file and empty the trash. It holds your passwords in plain text.

## Supported apps

| App | Export to choose | Passkeys | Files |
| --- | --- | --- | --- |
| Bitwarden | **.json**, with **Password protected** off | Yes | No |
| 1Password | **.1pux** | No | Yes |
| Proton Pass | Unencrypted **.zip**, with file attachments turned on | Yes | Yes |
| KeePassXC, KeePass | The **.kdbx** database itself | Yes | Yes |
| KeePassXC, KeePass | **XML** export | Yes | No |
| LastPass | Unencrypted **.csv** | No | No |
| Dashlane | **CSV** export (.zip) | No | No |
| Enpass | Unencrypted **.json** | No | No |
| RoboForm | **Account & Data → Export** (.csv) | No | No |
| AliasVault | **Import / Export → Export to CSV** | No | No |
| Apple Passwords | **Export All Passwords** (.csv) | No | No |
| Google Password Manager, Chrome | **Export passwords** (.csv) | No | No |

One-time codes come along wherever the export includes them. Google's export has none. RoboForm leaves identities and the cards inside them out of its file.

To move entries between your own Bramble vaults, use **Export selection** in one vault, then pick **Bramble (.bramble)** on the import screen. Passkeys and password history come too.

## Encrypted exports

- **Bitwarden**: Bramble can't open a password-protected export. Export again with **Password protected** off.
- **Dashlane**: the encrypted .dash file can't be read. Choose the CSV export.
- **KeePass**: enter the database's master password, and add its key file if it has one. Bramble opens KDBX4 databases. Save an older one as KDBX4 in KeePassXC, or import an XML export.

## Passkeys

Passkeys come along from:

- Bitwarden
- Proton Pass
- KeePassXC (.kdbx or XML)
- Another Bramble vault (.bramble)
- Any app that can [transfer to Bramble on an iPhone](#transfer-straight-from-another-app-iphone), like Apple Passwords

Bramble can't read passkeys from the other exports, including 1Password's .1pux. For those sites, sign in with your password and create a new passkey with Bramble.

Imported passkeys work right away and sync to your other devices. If one can't be read, the import summary names it before you import.

## Transfer straight from another app (iPhone)

On iOS 26 or later, another password app can hand your passwords, codes and passkeys straight to Bramble. No file is written, so there's nothing to delete. This is credential exchange (CXP and CXF), a FIDO Alliance standard built into iOS.

A transfer starts in the app you're leaving. From Apple Passwords:

1. Open **Passwords**, tap **More** (the three dots) and choose **Export Data to Another App**.
2. Choose what to send, then tap **Continue**.
3. Pick **Bramble** and confirm with Face ID or your passcode.
4. Bramble opens. If you have more than one vault, choose where the items go, then unlock.
5. Check what arrived, then choose **Import**.

Other apps that support credential exchange work the same way: find their export option and pick Bramble.

<Callout type="note">
Transfers work only in the iPhone app. On Android this feature needs Google Play services, which Bramble doesn't use. The browser extensions and desktop app use file imports.
</Callout>

**Another app on this device** in Bramble's import list only picks up a transfer that's already on its way. Start it from the other app.

## Importing twice

- An exact copy of something in your vault is skipped.
- An entry with the same site, username and password, or the same card number, is held back. Choose **Import them anyway** to add it.
- A login with the same site and username but a different password is added as a new entry.
