Add the second computer the same way you'd add a phone: with a pairing code from a device that already has your vault. That device can be your other computer or your phone.

## Check these first

- You make the code on a device that has your vault, and enter it on the computer you're adding. Not the other way round.
- The computer you're adding shows the **Join a device** tab. If it already has a vault, choose **Create another vault** on its unlock screen first.
- A computer can't scan the QR code. Choose **Copy** and paste the text code instead. On a phone, only **Scan QR code** inside Bramble reads it, not the camera app.

## Add the second computer

1. On a device that has your vault, open **Settings → Sync** and choose **Add a device** or **Add another device**. Enter your master password, choose **Continue**, then choose **Copy**.
2. Get the code to the new computer (see below) within 3 minutes.
3. On the new computer, paste it into **Pairing code** on the **Join a device** tab. Enter your master password and choose **Join vault**.
4. Check that both screens show the same symbols, and approve on the first device.

The full steps are in [Add a device](/docs/add-a-device).

## Getting the code across

- **Apple devices on the same Apple Account**: copy the code on your other Mac or your iPhone, and paste it on the new Mac. Universal Clipboard carries it.
- **Anything else**: send it to yourself in a way only you can open, like a note to yourself in an end-to-end encrypted messenger. Don't send it to anyone else.

The code works once and lasts 3 minutes, and nothing copies until you approve the symbols. [Is it safe to share my pairing code?](/docs/pairing-code-safety)

## Desktop app, extension, or both

Each computer can use the desktop app, the browser extension, or both.

- **One of them on each computer**: join each with its own code.
- **Both on the same computer**: join the desktop app with a code, then [link the extension to it](/docs/link-desktop-app). The browser doesn't need a code of its own.

Once joined, your computers and phone all sync with each other. They sync while they're unlocked and online at the same time. See [How sync works](/docs/how-sync-works).
