Any entry can hold files. Bramble encrypts each file on your device, the same way it encrypts your passwords.

## Add a file

1. Save the entry, then open it.
2. Under **Attachments**, choose **Attach a file** and pick the file.

Each file can be up to 90 MB. Bramble shows **Encrypting…** while it works.

In the browser extension's toolbar popup, choose **Popout to window to attach files** first. The popup closes when the file picker opens, so Bramble continues in a window.

## Open a file

Choose the open button next to the file.

- **Browser extension:** the file downloads to your computer.
- **Phone:** the share sheet opens, so you can view it or save it to another app.
- **Desktop app:** the file opens in its usual app.

On a phone and in the desktop app, Bramble deletes its unencrypted copy when your vault locks.

## Remove a file

Choose the bin button next to the file, then **Remove**. Deleting an entry removes its files too.

## Find entries with files

When any entry has a file, a paperclip button appears next to **Sort** above your list. Choose it to show only items with attachments. Search doesn't look inside file names.

## Sync

Files sync to every device in your vault's sync group. They move between your devices end-to-end encrypted, and no server keeps a copy, so a file arrives only while a device that has it is online and unlocked. Until then, the file shows why it isn't there yet, for example **Not on this device yet. Waiting for a device that has it.**

[Backups](/docs/back-up-your-vault) always include every file.

<Callout type="note" title="Firefox">
Firefox extensions can't connect straight to other devices, so Firefox sends and receives files only through the Bramble desktop app on the same computer. To add files in Firefox, [link it to the desktop app](/docs/link-desktop-app) first. Without the link, Firefox can still open files it already has.
</Callout>
