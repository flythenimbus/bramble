Bramble has no account to sign up for. You create a vault on one device, protect it with a master password, then add your other devices to it.

## Install Bramble

| Where | What to install |
| --- | --- |
| Chrome, Brave, Edge, Vivaldi, Opera, Arc | The extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/bramble/kmokhdhoggbdcgoepifeckhgbfakaknm) |
| Firefox, Zen, LibreWolf, Waterfox | The extension from [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/bramble/) |
| iPhone | Bramble Password Manager from the [App Store](https://apps.apple.com/us/app/bramble-password-manager/id6783071787) |
| Android | The signed APK from [Bramble's releases on GitHub](https://github.com/bramble-sh/bramble/releases). It doesn't need Google Play. |
| Your computer | The desktop app. See [Install the desktop app](/docs/install-desktop-app). |

Install Bramble wherever you want your passwords. You create a vault once, on the first device. Every other device joins that vault.

## Create your vault

1. Open Bramble and choose **Create your vault**. The browser extension opens this in a new tab.
2. Stay on **Create new vault**.
3. Enter a **Master password**, then type it again under **Confirm master password**.
4. Choose **Create vault**.

Your master password needs at least 8 characters. If Bramble says it's weak, pick a longer one, or tick **Use this password anyway**. A long phrase of a few unrelated words is strong and easy to remember.

<Callout type="warning" title="Nobody can reset your master password">
Bramble never stores or sends your master password, so we can't reset it for you. Your recovery code is the only way back in if you forget it.
</Callout>

<Callout type="tip" title="Already use the desktop app?">
In the browser extension, choose **Link** next to **Using Bramble desktop?** instead of creating a new vault. See [Link the browser extension to the desktop app](/docs/link-desktop-app).
</Callout>

## Save your recovery code

Next, Bramble shows **Save your recovery code**. You won't see this code again.

1. Choose **Copy** or **Download**, or write the code down.
2. Keep it somewhere safe and offline, away from your devices.
3. Choose **I've saved it, continue**.

Your vault opens, ready for your first item. In the browser extension, close the tab and open Bramble from the toolbar.

Lost the code? Make a new one in **Settings → Security** on each of your devices. See [Ways to unlock your vault](/docs/unlock-methods#recovery-code).

## On your other devices

Don't create a new vault on each device. Install Bramble, choose **Create your vault**, then switch to the **Join a device** tab and pair it with the device that has your vault. See [Add a device](/docs/add-a-device).
