Bramble은 브라우저 안에서 작동하며 비밀을 사용자의 기기 안에 보관하는 비밀번호 관리자입니다. 계정도 없고, 볼트를 보관하는 서버도 없고, 해킹되어 모든 정보를 유출할 회사도 없습니다. 볼트도, 비밀번호도 사용자가 직접 보관합니다. 그게 전부입니다.

Firefox, LibreWolf, Waterfox, Zen 및 기타 Firefox 기반 브라우저에서 작동합니다. 설치하면 약 1분 안에 실행할 수 있습니다.

주요 기능

비밀번호는 사용자의 기기에서 암호화되어 브라우저 자체의 확장 프로그램 저장소, 즉 사용자의 컴퓨터에 저장됩니다. 계정도 없고 볼트를 보관하는 서버도 없습니다. 한 번 설정하면 로그인 자동 입력, 새 항목 저장, 비밀번호 생성이 바로 시작됩니다.

기기가 두 대 이상인가요? 기기를 페어링하면 Bramble이 종단 간 암호화된 채널을 통해 기기 간에 볼트를 동기화합니다. 기기를 연결해 주는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않으므로, 비밀이 다른 사람의 서버에 저장되는 일은 없습니다.

상세 기능

- 항상 로컬 우선. 암호화된 볼트는 사용자의 기기, 브라우저 저장소에만 보관됩니다. 계정도 없고 서버 사본도 없습니다.
- 다중 기기 동기화. 기기들은 종단 간 암호화된 채널을 통해 동기화 상태를 유지합니다. 기기를 연결하는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않습니다.
- 견고한 암호화. 키에는 Argon2id, 데이터에는 AES-256-GCM, 모든 항목이 고유 키를 갖도록 엔벨로프 암호화를 사용합니다. 비밀은 사용 후 메모리에서 삭제됩니다.
- 전부 암호화. 사이트 이름, 사용자 이름, 메모 등 모든 것이 암호화됩니다.
- 도메인 인식 자동 입력. www.example.com, ca.accounts.example.com, example.com이 모두 하나의 로그인과 일치합니다. 항목 하나로 여러 URL을 처리합니다.
- 로그인 이상. 로그인, 결제 카드, 보안 메모, SSH 키를 각각 전용 필드로 저장합니다.
- 내장 비밀번호 생성기.
- 암호화된 백업. 언제든지 볼트 전체를 암호화된 파일로 내보내 오프라인 복사본으로 보관할 수 있습니다. 열려면 마스터 비밀번호가 필요합니다.
- 복구 코드. 설정 시 모든 볼트에 보안 복구 코드가 제공됩니다. 마스터 비밀번호와 독립적으로 볼트를 여는 인쇄 가능한 백업입니다.
- TOTP / 2FA 코드. otpauth:// URI 또는 비밀 키를 붙여넣으면 Bramble이 코드를 생성합니다.
- 선택적 유출 확인. k-익명성을 활용한 Have I Been Pwned 조회로, 비밀번호에 관한 어떤 정보도 기기를 벗어나지 않습니다. 기본적으로 꺼져 있습니다.
- 유휴 상태 15분 후 자동 잠금(구성 가능).
- KeePass, Bitwarden, Proton Pass, 1Password에서 가져오기.

로컬 우선인 이유

클라우드형 비밀번호 관리자는 모든 사용자의 볼트를 자사 서버에 보관하는데, 이는 하나의 거대한 공격 표적이 됩니다. 하나가 유출되면 볼트 하나가 아니라 수백만 개가 한꺼번에 유출되며, 많은 경우 몇 달 뒤에야 공개됩니다.

Bramble은 이를 뒤집습니다.
- 유출될 서버가 없습니다. 볼트는 절대 사용자의 통제를 벗어나지 않습니다.
- 계정도, 구독도, 원격 측정도 없습니다. 가입할 것이 없습니다.
- 사용자의 기기, 사용자의 데이터. 여러 기기 간에 동기화하거나, 한 기기에 오프라인으로 보관하거나, 암호화된 백업으로 내보내 사용자가 직접 보관할 수 있습니다. 어떤 데이터도 타사 서버에 보관되지 않습니다.
- 신뢰할 것은 코드뿐입니다. 코드는 오픈소스이며 전적으로 사용자의 기기에서 실행됩니다.

암호화 작동 방식

Bramble은 LUKS 방식의 키 슬롯과 엔벨로프 암호화를 사용합니다. 하나의 무작위 볼트 키가 데이터를 보호합니다. 각 잠금 해제 방법(마스터 비밀번호, 복구 코드)은 동일한 볼트 키의 사본을 풀 수 있는 고유한 키 암호화 키를 파생합니다. 따라서 잠금 해제 방법을 추가하거나 제거해도 어떤 항목도 다시 암호화할 필요가 없습니다. 그런 다음 볼트 키가 모든 항목에 대해 새로운 항목별 키를 풉니다. 모든 암호화는 AES-256-GCM 방식입니다.

KeePass에서 넘어오셨나요?

익숙하실 것입니다. 암호화된 볼트, 사용자 직접 통제, 클라우드 중개자 없음에 더해 Bramble은 KDBX4 파일을 가져옵니다. 차이점은 다음과 같습니다. 브라우저 안에서 작동하고(별도 데스크톱 앱이나 플러그인 브리지 없음), 도메인 일치와 페이지 내 드롭다운을 갖춘 자동 입력이 내장되어 있으며, 여러 플러그인 대신 Argon2id와 AES-256-GCM을 사용하는 하나의 최신 빌드로 제공됩니다. 깔끔한 UI와 다크 모드가 포함되어 있습니다.
