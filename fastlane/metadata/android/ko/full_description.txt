Bramble은 로컬 우선 암호 관리자입니다. 암호는 타인의 서버가 아닌, 기기의 암호화된 보관함에 저장됩니다. 만들어야 할 계정도 없고, 외부로 전송되는 정보도 없습니다.

모든 암호화 작업은 Rust 코어에서 실행됩니다. Argon2id가 키를 파생하고, AES-256-GCM이 데이터를 암호화하며, envelope encryption이 각 항목에 고유 키를 부여합니다. 사이트 이름, 사용자 이름, 메모가 모두 암호화되며, 비밀값은 사용 후 메모리에서 삭제됩니다.

기능
- 앱과 브라우저에 암호 및 일회용 코드 자동 완성
- 패스키: 지원하는 사이트와 앱에서 Bramble을 사용자 본인의 인증자로 사용하여 패스키 생성 및 로그인
- 지문, 얼굴, 마스터 암호 또는 복구 코드로 잠금 해제
- 로그인, 결제 카드, 보안 메모, SSH 키 저장(각각 전용 필드)
- 강력한 암호 생성기 내장
- TOTP / 2FA: otpauth URI 또는 비밀 키를 추가하면 Bramble이 6자리 코드 생성
- KeePass(KDBX4)에서 가져오기, 키 파일 포함
- 복구 코드: 마스터 암호와 별개로 보관함을 잠금 해제하는 인쇄 가능한 고엔트로피 백업
- k-anonymity 기반 선택적 유출 검사 — 암호에 관한 어떤 정보도 기기를 떠나지 않음
- 비활성 후 자동 잠금
- 사용자 본인의 기기 간 P2P 동기화. 클라우드도, 데이터를 보관하는 중계 서버도 없음.

개인정보 보호
Bramble에는 계정도, 구독도, 원격 측정도 없습니다. 보관함은 항상 사용자의 통제를 벗어나지 않으며, 코드는 전적으로 기기에서 실행됩니다.
