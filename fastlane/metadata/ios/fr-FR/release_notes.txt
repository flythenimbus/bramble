Nouveautés de cette version :

- Face ID et Touch ID signifient désormais exactement cela. Sur iPhone, ils ont toujours partagé un même verrou avec le code d’accès de votre appareil, de sorte que toute personne connaissant ce code pouvait ouvrir votre coffre sans votre mot de passe principal. Le déverrouillage par votre visage ou votre empreinte digitale est désormais distinct du code d’accès, et c’est ce que vous obtenez par défaut.
- Si vous préférez conserver le code d’accès comme solution de secours, un nouvel interrupteur « Autoriser le recours au code d’accès » se trouve sous la ligne Face ID dans Réglages, sous Sécurité. Activez-le pour que le code d’accès de votre appareil ouvre à nouveau le coffre. Sur un iPhone où aucun visage ni aucune empreinte n’est configuré, il reste activé automatiquement, car le code d’accès y est le seul verrou disponible.
- Ces deux réglages s’appliquent également au remplissage automatique : ainsi, remplir un mot de passe dans une autre app exige exactement la même chose que l’app elle-même. L’ajout ou la suppression d’un visage ou d’une empreinte dans les Réglages iOS efface désormais aussi la clé enregistrée sur cet appareil, de sorte qu’un visage nouvellement ajouté ne puisse pas être utilisé pour accéder au coffre. Déverrouillez une fois avec votre mot de passe principal pour le configurer à nouveau.

Pas de compte, pas de cloud. Tout reste sur vos appareils.
