Nouveautés de cette version :

- Vous avez oublié votre mot de passe principal ? Après avoir déverrouillé l’application avec votre code de récupération, vous pouvez définir un nouveau mot de passe immédiatement, en utilisant ce code au lieu de l’ancien mot de passe.
- Import de vos identifiants depuis Dashlane et RoboForm.
- Si la synchronisation cesse de fonctionner sur cet appareil, l’écran Synchronisation vous l’indique désormais et vous explique comment y remédier, au lieu d’afficher « Synchronisé ».
- L’ajout d’un appareil fonctionne de nouveau après l’expiration d’une invitation précédente.
- Les mots de passe révélés sont de nouveau masqués lorsque vous quittez l’application.
- Après la suppression d’un coffre, l’application ouvre celui qui reste.
- Mises à jour de sécurité des bibliothèques sur lesquelles repose l’application.

Pas de compte, pas de cloud. Tout reste sur vos appareils.
