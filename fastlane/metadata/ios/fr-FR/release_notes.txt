Nouveautés de cette version :

- Face ID et Touch ID signifient désormais exactement ce que leur nom indique. Sur iPhone, ils partageaient jusqu’à présent le même verrou que le code d’accès de votre appareil, si bien que toute personne connaissant ce code pouvait ouvrir votre coffre sans votre mot de passe principal. Le déverrouillage avec votre visage ou votre empreinte digitale est désormais distinct du code d’accès, et c’est ce comportement qui est activé par défaut. Si vous préférez conserver le code d’accès comme solution de secours, un nouveau commutateur « Autoriser le code d’accès de secours » est disponible sous la ligne Face ID dans Réglages, dans la section Sécurité.
- L’ajout ou la suppression d’un visage ou d’une empreinte digitale dans les Réglages iOS efface désormais la clé enregistrée sur cet appareil, afin qu’un visage nouvellement ajouté ne puisse pas être utilisé pour accéder au coffre. Déverrouillez une fois avec votre mot de passe principal pour rétablir la clé. Ces deux réglages s’appliquent aussi au remplissage automatique : le remplissage d’un mot de passe dans une autre app demande donc exactement le même déverrouillage que Bramble.
- Vous pouvez rechercher vos identifiants pendant le remplissage. Lorsque vous touchez un champ de mot de passe dans une autre app et que Bramble ne reconnaît pas le site, la liste affichée était auparavant l’ensemble de vos identifiants enregistrés, en une seule longue liste. Une zone de recherche apparaît désormais au-dessus.
- Bramble peut accepter une clé de configuration 2FA transmise par une autre app. Choisissez Bramble dans Réglages, Apps, Mots de passe, Configurer les codes dans, et une clé de double authentification envoyée depuis ailleurs sur votre téléphone arrive ici, où vous choisissez à quel identifiant elle appartient. Scanner un code QR ou coller une clé fonctionne toujours comme avant.
- La synchronisation avec un navigateur devrait désormais aboutir. Un téléphone et une extension de navigateur pouvaient passer beaucoup de temps à se découvrir sans jamais vraiment se stabiliser, si bien que les modifications apportées dans l’un mettaient beaucoup plus de temps qu’elles n’auraient dû à apparaître dans l’autre. La connexion n’est plus interrompue et reconstruite en continu sous elle-même.

Pas de compte, pas de cloud. Tout reste sur vos appareils.
