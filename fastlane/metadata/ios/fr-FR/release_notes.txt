Nouveautés de cette version :

- Correction d’un bug pouvant empêcher le déverrouillage d’un coffre synchronisé, même avec le bon mot de passe principal. Si Bramble trouve un coffre dans cet état, il le restaure désormais à partir de la copie sauvegardée avant que le problème ne survienne.
- Importer à partir d’Apple Passwords et de Google Password Manager. Exporter un fichier .csv depuis l’une ou l’autre et l’ouvrir dans Bramble.
- Les options d’importation et de sauvegarde dans les Réglages sont désormais regroupées selon la source du fichier, ce qui clarifie celle que vous souhaitez utiliser.

Sans compte, sans cloud. Tout reste sur vos appareils.
