Neu in dieser Version:

- Öffnen Sie die App und Face ID wartet bereits: keine Taste zu drücken, kein Passwort einzugeben. Aktivieren Sie „Beim Öffnen entsperren“ unter „Einstellungen“ > „Sicherheit“ direkt unter dem Schalter für Face ID, und der Entsperrbildschirm fordert sofort Face ID an, sobald er erscheint. Die Funktion bleibt deaktiviert, bis Sie sie einschalten. Geräte mit Touch ID oder Code funktionieren auf dieselbe Weise.
- Wenn Sie den Tresor selbst sperren, bleibt er auch gesperrt. Beim Tippen auf die Sperrtaste bleiben Sie auf dem Passwortbildschirm, statt sofort Face ID abzufragen, sobald Sie auf Ihr Telefon schauen.

Kein Konto, keine Cloud. Alles bleibt auf Ihren Geräten.
