Was ist neu in dieser Version:

- Face ID und Touch ID bedeuten jetzt genau das. Auf dem iPhone haben sie sich bisher immer ein Schloss mit Ihrem Gerätecode geteilt, sodass jeder, der diesen Code kannte, Ihren Tresor ohne Ihr Master-Passwort öffnen konnte. Das Entsperren mit Ihrem Gesicht oder Ihrem Fingerabdruck ist jetzt vom Code getrennt, und das ist die neue Standardeinstellung.
- Wenn Sie den Code lieber als Backup behalten möchten, finden Sie in den Einstellungen unter „Sicherheit“ in der Zeile „Face ID“ den neuen Schalter „Code-Fallback erlauben“. Schalten Sie ihn ein, und Ihr Gerätecode öffnet den Tresor wieder. Auf einem iPhone ohne eingerichtetes Gesicht oder Fingerabdruck bleibt er von selbst eingeschaltet, da der Code dort das einzige Schloss ist.
- Beide Einstellungen gelten auch für AutoFill. Beim Ausfüllen eines Passworts in einer anderen App wird daher genau dieselbe Authentifizierung verlangt wie in der App selbst. Das Hinzufügen oder Entfernen eines Gesichts oder Fingerabdrucks in den iOS-Einstellungen löscht jetzt auch den gespeicherten Schlüssel dieses Geräts, sodass ein neu hinzugefügtes Gesicht nicht für den Zugriff verwendet werden kann. Entsperren Sie einmal mit Ihrem Master-Passwort, um ihn erneut einzurichten.

Kein Konto, keine Cloud. Alles bleibt auf Ihren Geräten.
