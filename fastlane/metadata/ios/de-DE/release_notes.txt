Neu in dieser Version:

- Face ID und Touch ID bedeuten jetzt genau das. Auf dem iPhone haben sie bisher immer eine Sperre mit Ihrem Gerätecode geteilt, sodass jeder, der diesen Code kannte, Ihren Tresor ohne Ihr Master-Passwort öffnen konnte. Das Entsperren mit Ihrem Gesicht oder Fingerabdruck ist jetzt vom Code getrennt und standardmäßig aktiv. Wenn Sie den Code lieber als Backup behalten möchten, gibt es unter „Einstellungen“, „Sicherheit“ in der Zeile „Face ID“ einen neuen Schalter „Passcode-Fallback erlauben“.
- Das Hinzufügen oder Entfernen eines Gesichts oder Fingerabdrucks in den iOS-Einstellungen löscht jetzt den gespeicherten Schlüssel auf diesem Gerät, sodass ein neu hinzugefügtes Gesicht nicht zum Entsperren verwendet werden kann. Entsperren Sie einmal mit Ihrem Master-Passwort, um es erneut einzurichten. Beide Einstellungen gelten auch für AutoFill, sodass beim Ausfüllen eines Passworts in einer anderen App genau das abgefragt wird, was die App abfragt.
- Sie können beim Ausfüllen nach Ihren Logins suchen. Wenn Sie in einer anderen App auf ein Passwortfeld tippen und Bramble die Website nicht erkennt, war die Liste bisher alles, was Sie gespeichert haben – eine lange Liste zum Scrollen. Jetzt gibt es darüber ein Suchfeld.
- Bramble kann einen 2FA-Einrichtungsschlüssel von einer anderen App übernehmen. Wählen Sie Bramble unter „Einstellungen“, „Apps“, „Passwörter“, „Codes einrichten in“ aus, und ein von einer anderen Stelle auf Ihrem Telefon gesendeter Zwei-Faktor-Schlüssel kommt hier an, wo Sie auswählen, zu welchem Login er gehört. Das Scannen eines QR-Codes oder das Einfügen eines Schlüssels funktioniert weiterhin wie bisher.
- Die Synchronisierung mit einem Browser sollte jetzt abgeschlossen werden. Ein Telefon und eine Browser-Erweiterung konnten lange damit verbringen, einander zu finden, und kamen nie ganz zur Ruhe, sodass Änderungen auf einem Gerät viel länger brauchten, um auf dem anderen zu erscheinen, als sie sollten. Die Verbindung wird nicht mehr intern abgebaut und neu aufgebaut.

Kein Konto, keine Cloud. Alles bleibt auf Ihren Geräten.
