Neu in dieser Version:

- Beim Hinzufügen eines Geräts wird jetzt auf beiden Bildschirmen eine 12-stellige Nummer angezeigt. Ihr Tresor wird erst übertragen, wenn Sie bestätigen, dass die Nummern übereinstimmen. So kann ein Code, den jemand anderes gesehen hat, nicht mehr verwendet werden, um Ihren Tresor auf sein Gerät zu kopieren.
- Pairing-Codes laufen jetzt nach drei Minuten ab und funktionieren nur einmal. Behandeln Sie einen Code wie Ihr Master-Passwort: Jeder, der ihn sieht, während er auf dem Bildschirm angezeigt wird, könnte versuchen, ihn zu verwenden.
- Bitte aktualisieren Sie Bramble auf jedem Gerät, das Sie synchronisieren. Ein aktualisiertes Gerät kann nicht mit einem Gerät verbunden werden, auf dem noch eine ältere Version läuft.

Kein Konto, keine Cloud. Alles bleibt auf Ihren Geräten.
