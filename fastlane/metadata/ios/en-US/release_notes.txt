What's new in this release:

- Pairing with another device no longer gives up while you are confirming it. The countdown on the pairing code kept running after the code had been entered, so reaching the confirmation with seconds left could end the pairing and tell the other device it had been refused, which nobody had done. The countdown now stops once the code is used, and confirming gets a full window of its own.
- Settings, About has a new Rate Bramble link, if you would like to leave a review.

No account, no cloud. Everything stays on your devices.
