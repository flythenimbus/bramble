What's new in this release:

- Fixed a bug that could stop a synced vault from unlocking, even with the correct master password. If Bramble finds a vault left in that state, it now restores it from the copy saved before the problem happened.
- Import from Apple Passwords and Google Password Manager. Export a .csv from either one and open it in Bramble.
- Import and backup options in Settings are now grouped by where the file comes from, so it's clearer which one you want.

No account, no cloud. Everything stays on your devices.
