Bramble은 로컬 우선 비밀번호 관리자입니다. 비밀번호는 다른 사람의 서버가 아닌 사용자 기기의 암호화된 볼트에 저장됩니다. 생성할 계정도 없고 외부로 전송되는 데이터도 없습니다.

모든 암호화 기능은 Rust 코어에서 실행됩니다. Argon2id가 키를 유도하고, AES-256-GCM이 데이터를 암호화하며, 엔벨로프 암호화(Envelope Encryption)가 각 항목에 고유한 키를 부여합니다. 사이트 이름, 사용자 이름, 메모는 모두 암호화되며, 비밀 값은 사용 후 메모리에서 삭제됩니다.

기능
- 키보드에서 바로 앱과 Safari에 비밀번호 및 일회용 코드 자동 완성
- 패스키: 지원하는 사이트와 앱에서 Bramble을 나만의 인증자로 사용하여 패스키 생성 및 로그인
- Face ID, Touch ID, 마스터 비밀번호 또는 복구 코드로 잠금 해제
- 로그인 정보, 결제 카드, 보안 메모, SSH 키를 각각 전용 필드에 저장
- 내장형 강력한 비밀번호 생성기
- TOTP / 2FA: otpauth URI 또는 시크릿 추가 시 Bramble이 6자리 코드 생성
- KeePass(KDBX4)에서 가져오기, 키 파일 포함
- 복구 코드: 마스터 비밀번호와 독립적으로 볼트를 잠금 해제하는 인쇄 가능한 고엔트로피 백업
- k-익명성을 사용한 선택적 유출 검사. 비밀번호에 관한 어떤 정보도 기기를 떠나지 않습니다.
- 비활성 시 자동 잠금
- 사용자 자신의 기기 간 P2P 동기화. 클라우드도, 데이터를 보관하는 중계 서버도 없습니다.

개인정보 보호
Bramble에는 계정, 구독, 원격 측정이 없습니다. 볼트는 절대 사용자의 통제를 벗어나지 않으며, 코드는 전적으로 사용자의 기기에서 실행됩니다.
